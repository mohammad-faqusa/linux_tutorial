## 43. Updating and Installing Software in Ubuntu: apt

### tasks 
* apt upgrade
  * check the packages to upgrade and install 
* install package : cowsay 
* run cowsay 
* remove cowsay 

### apt 
* apt update : 
  * refresh and update the packages 
* apt upgrade 
  * update and allows the install of additional packages 
  * in case of kernal message , restart the system if required 
* apt full-upgrade or apt dist-upgrade 
  * maybe should remove other packages in order to install a package 
  * do not remove anything installed **manually** 
  * might break something, needs carful debugging 
* apt install 
  * install additional package 
* apt remove 
* there are additional apt tools
  * apt get-upgrade , same to apt upgrade 
  * ...
