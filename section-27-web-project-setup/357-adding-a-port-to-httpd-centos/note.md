# 357. Adding a Port to Apache (httpd) [CentOS]

## Why Add Another Port?

By default, Apache listens on:

```text
Port 80  → HTTP
Port 443 → HTTPS
```

Sometimes we may want Apache to listen on an additional port.

Examples:

* Testing a website
* Running multiple web applications
* Development environments
* Internal services

---

## Apache Can Listen on Multiple Ports

Apache supports listening on multiple ports simultaneously.

Example:

```apache
Listen 80
Listen 8080
```

Result:

```text
Apache
   ├── Port 80
   └── Port 8080
```

Requests to either port will be accepted.

---

## Creating an Additional Configuration File

Instead of modifying the main configuration file, it is usually better to create a new configuration file inside:

```bash
/etc/httpd/conf.d
```

Example:

```bash
sudo nano /etc/httpd/conf.d/custom-port.conf
```

---

## Add the Listen Directives

Example:

```apache
Listen 80
Listen 8080
```

This instructs Apache to listen on both ports.

---

## Verify the Configuration

Before restarting Apache:

```bash
sudo httpd -t
```

Expected output:

```text
Syntax OK
```

Always test the configuration before restarting the service.

---

## Restart Apache

Apply the changes:

```bash
sudo systemctl restart httpd
```

---

## Verify Apache Is Listening

Check listening ports:

```bash
ss -tulpn | grep httpd
```

Example:

```text
LISTEN 0 511 *:80
LISTEN 0 511 *:8080
```

This confirms that Apache is listening on both ports.

---

## Test in a Browser

Open:

```text
http://localhost
```

or

```text
http://server-ip
```

---

Open the new port:

```text
http://localhost:8080
```

or

```text
http://server-ip:8080
```

If configured correctly, Apache should serve the same website.

---

## Common Problem: Firewall

Even if Apache is listening on port 8080, the firewall may block incoming connections.

Check open ports:

```bash
sudo firewall-cmd --list-ports
```

---

Allow port 8080:

```bash
sudo firewall-cmd --add-port=8080/tcp --permanent
```

Apply changes:

```bash
sudo firewall-cmd --reload
```

---

Verify:

```bash
sudo firewall-cmd --list-ports
```

Example:

```text
8080/tcp
```

---

## Viewing Apache Logs

If Apache fails to start after the configuration change:

```bash
sudo journalctl -u httpd.service
```

This displays logs generated by the Apache service.

---

### Useful Options

Show the latest logs:

```bash
sudo journalctl -u httpd.service -n 50
```

---

Follow logs in real time:

```bash
sudo journalctl -u httpd.service -f
```

---

## Example Error

Suppose we accidentally configure:

```apache
Listen abc
```

and restart Apache.

Checking logs:

```bash
sudo journalctl -u httpd.service
```

might show:

```text
Syntax error on line ...
```

This helps identify configuration problems.

## Important Takeaway

Apache can listen on multiple ports simultaneously.

Example:

```apache
Listen 80
Listen 8080
```

After modifying the configuration:

1. Test it:

```bash
sudo httpd -t
```

2. Restart Apache:

```bash
sudo systemctl restart httpd
```

3. Verify with:

```bash
ss -tulpn | grep httpd
```

4. Troubleshoot using:

```bash
sudo journalctl -u httpd.service
```

This is a common technique when hosting development, testing, or multiple web services on the same server.
