## 13. Installing CentOS Stream [VirtualBox]

### the process 
1. go to centos page 
2. select centOS stream 9 
3. run on virtualbox 
4. you can change the capture key 
5. when running the vm, select the second choice (test and install ...)
6. after the GUI started 
7. select the keyboard layout 
8. software selection : 
   * workstation 
9. select the install destination 
10. root password 
11. user creation 
    * name 
    * make this user as admin 
    * assign password 
12. begin installation 
13. installation complete , reboot the system 
14. remove disk from virtual machine 
15. restart again
