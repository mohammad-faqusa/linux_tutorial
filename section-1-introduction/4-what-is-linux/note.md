### operating system

what is linux : 
* linux is the kernal of a family of open-source unix-like operating systems(os); 
* what is os ? 
* unix : powerful OS , multi users , multitasking ... 
* kernal : the core part of os 
* linux : a fork of unix 
* open-source : free to use , free to modify , free to redistribute 
* unix-like : unix + linux 
  * manage resources : hardware 

#### what is the GNU project
* stands for : GNU's Not Unix 
* the goal : create free and open source os 
* most GNU software is released under the GNU General Public License(GPL), promoting the freedom to use, modify and distribute the code 
  * the linux kernal is created and released under GPL 

* GNU povices additional tools and utilities 
* linux provides the kernal
