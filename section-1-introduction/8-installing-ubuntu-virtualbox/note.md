## 8. Installing Ubuntu [VirtualBox]

#### the process 
1. download the LTS version image from ubuntu page 
2. create virtual machine on virtualbox 
3. configure : 
   * memory : 2 giga minumum 
   * cpu cores : 2 or 4 
   * hard disk : 100 GByte 
4. run the virtual machine 
5. click to `try and install`
6. change host key , if you want  (from settings -> preferences -> input -> virtuah machine)
7. installation setup : 
   1. select keyboard 
   2. next 
   3. normal installation
