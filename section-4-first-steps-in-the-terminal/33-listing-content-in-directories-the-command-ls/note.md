## 33. Listing Content in Directories: the Command `ls`


### tasks : 
* list the contents of a directory
* show hidden 
* reverse 
* sort by time 
* color output 
* ls with specific path

### listing the contents: ls 
* options : 
  * -a : show hidden files
  * -l : show detailed information
  * -R : recursively list subdirectories
  * -t : sort by modification time
  * -r : reverse the sort order
  * -h : show human-readable sizes
  * -S : sort by size
  * -X : sort by extension
  * -F : append a slash to directories
  * -1 : one file per line
  * -i : show inode numbers
  * -c : sort by change time
  * -u : sort by access time
  * -s : sort by size
  * -m : sort by modification time
* most common options : 
  * t, r, a, --color={always,auto,never}
* specify directory path: 
  * ls -ta --color ~/Desktop
