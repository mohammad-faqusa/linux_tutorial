## 32. Displaying and Changing the Current Directory: the Commands `pwd` & `cd`


### tasks : 
* print the current working directory
* use cd 
* move to root 
* move to upper directory 
* move to home directory


### the pwd command 
* to find our current directory
* pwd : (print working directory) 
```bash
pwd 
```
* `~` home directory


### the change directory cd 
* cd [directory_name]
* cd / : change root path 
* cd .. navigate up one directory
* cd ~ or cd : move to home directory
